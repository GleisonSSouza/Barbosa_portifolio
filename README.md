# Laís Barbosa · Lash & Brow

Site da Laís Barbosa: serviços, cursos, feedbacks e agendamento online, com painel para ela editar tudo.

## Painel

Link **Área da Laís** no rodapé, ou `site/#painel`.

- Usuário: `lais`
- Senha: `barbosa2026` (troque em `js/config.js`)

Agenda: a Laís abre ou fecha cada mês na aba **Painel** ou no **Calendário**. A cliente só escolhe dia em mês aberto e vê só os horários livres. Pelo painel, a Laís agenda em qualquer mês.

Categorias: na aba **Serviços** a categoria é escolhida numa lista. Ao criar uma nova, o site avisa se já existe uma igual ou parecida ("Depilçao" → "Depilação") e permite renomear, juntar, excluir e ordenar.

Modo demonstração: o que é editado e agendado fica salvo só no navegador onde foi feito.
